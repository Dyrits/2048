# 2048

A Java implementation of the 2048 puzzle game, built as a CodeGym Game Task.

## About The Project

Built for the CodeGym "Game Tasks - 2048" project. The game is played on a 4x4 board: a tile with a value of 2 (90% probability) or 4 (10%) appears each round; tiles can be moved to one of the four sides, and when two tiles with the same value collide they merge and the value doubles. The objective is to reach a tile with the value 2048; the player loses when no move is possible.

Made from scratch following specific instructions; several elements (such as the game engine) were provided by the related course.
